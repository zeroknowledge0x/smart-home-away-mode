## The line

> My smart home locked me out. As I stood freezing on the porch, it asked if I'd like to activate Away Mode.

The setup is an ordinary smart-home failure: the house has locked its own owner out. The turn is the machine's airtight, useless logic — it has correctly detected that nobody is inside, so it offers to switch on "Away Mode," completely blind to the fact that it is the reason the owner is standing in the cold. No explanation needed: the punch is a settings menu where a human would have said "let my owner in."

A joke a friend can repeat in one breath: the house that locked you out then helpfully asked whether you'd like it to pretend you were never there.
